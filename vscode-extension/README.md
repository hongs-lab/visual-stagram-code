# Visual Stagram Code (VS Code 확장)

쓰던 VS Code 안에서 인스타그램 DM을 파이썬 코드처럼 봅니다.

## 필요한 것

Visual Stagram Code 데스크톱 앱이 설치되어 있고, 그 앱에서 인스타그램에 한 번 로그인되어 있어야 합니다.
확장은 그 앱을 창 없이 뒤에서 실행해 대화를 가져옵니다. 로그인과 비밀번호는 앱 안의 instagram.com 페이지에서만 다룹니다.

## 쓰는 법

- 탐색기 아래 `DIRECT` 목록의 `이름.py` 를 누르면 대화가 파이썬 파일로 열립니다
- `print(...)` 는 받은 메시지(왼쪽 파란 막대), `input(...)` 은 내가 보낸 메시지(초록 막대)입니다
- 대화 파일에서 `Enter` : 입력창이 뜨고, 쓰고 다시 `Enter` 를 누르면 전송됩니다
- `Cmd+O` (Windows는 `Ctrl+O`) : 파일 첨부. 그다음 `Enter` 두 번으로 전송
- `Alt+↑` 또는 맨 위로 스크롤 : 이전 메시지 불러오기
- 사진 줄에 마우스를 올리면 미리보기가 뜹니다
- 설정 `visualStagram.camouflage` (0, 2, 4, 8) : 메시지 사이에 섞는 위장 코드의 양
